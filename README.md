# BZX 网页版小游戏合集

安卓应用 **bzxandroidgames** 的网页复刻版：完整还原大厅、设置页与全部七款游戏的逻辑、界面与动画，并针对电脑屏幕与鼠标做了适配。

## 运行方式

无需构建、无任何依赖——直接**双击 `index.html`** 即可离线游玩（音效已内嵌为 base64，图片为本地资源）。

也可以用任意静态服务器托管，例如：

```
cd E:\bzxwebgames
python -m http.server 8080
# 打开 http://localhost:8080
```

## 桌面适配一览

- 2048：方向键 / WASD，鼠标拖动滑棋盘
- 贪吃蛇：方向键 / WASD / 空格暂停开始
- 俄罗斯方块：完整键位（含长按连发的屏幕按钮）
- 五子棋：鼠标悬停显示幽灵落子
- 扫雷：左键翻开 + 右键插旗 + 数字弦开
- 蜘蛛纸牌：鼠标拖拽 + 悬停绿色高亮 + 抓取光标
- 全站：浏览器返回键（hash 路由）等价于安卓返回键；切走标签页自动暂停（等价 ON_PAUSE）

## 回归测试

安装 Node.js 后运行 `node --test tests/*.test.cjs`，验证俄罗斯方块和五子棋的关键逻辑。五子棋对弈基准可通过 `node tests/gomoku-extreme-match.cjs` 单独运行。
