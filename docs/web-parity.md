## 数独

- 三档难度按网页实际常量使用 40 / 31 / 25 个提示数为挖洞目标。每次移除提示数都检查唯一解，若无法继续移除或超过生成时间预算，会保留更多提示数。难度标签表示提示数目标，不额外声称按解题技巧评级。
- 初始显示空白棋盘，只有点击「开始游戏」后才生成题目并开始计时。生成工作在后台线程执行；重开或更换难度会取消旧任务的结果接入。
- 给定数字不可修改；玩家数字允许重复以便显示冲突。冲突检查覆盖每行、每列和全部九宫，不依赖隐藏答案判断。
- 同行 / 同列 / 同宫、相同数字、所选格与冲突分别高亮。候选数使用九位掩码，在格内按 3×3 排列；支持开关、再次点击取消、擦除，以及填数或擦除后的完整撤销。
- 最多保存 200 次编辑；通关条件为棋盘填满且没有重复冲突，通关后停止计时并锁定输入。最佳用时支持合法的零秒成绩。
- 仅当前数独页且 Activity 为 `RESUMED` 时计时；退后台、返回大厅与完成后不计时。每次从大厅进入重新回到等待开始的新局，与网页端保持一致。
- 外接键盘：方向键移动、1–9 填数、Backspace / Delete / 0 擦除、N 切换笔记。
- 本地键：`sudokuDifficulty`、`sudokuNoteMode`、`sudokuBest_EASY`、`sudokuBest_MEDIUM`、`sudokuBest_HARD`。

## 蜘蛛纸牌

- 每列发牌间隔 60ms，单张飞行 260ms，牌背从右下方牌堆飞往目标列，落地变成正面并弹跳。动画展示发牌前的牌列加上新牌，全部落地后再展示规则引擎自动收牌的最终结果，避免完整顺子立即消失造成落点错误。
- 发牌动画期间禁止连点发牌、拖动、撤销、换花色、提示和重开；返回大厅仍可用。离开界面或退后台会清理浮动牌，规则结果保留，不留下残影。
- 拖动的原牌隐藏，浮动副本显示；合法落点绿色高亮，非法落点恢复原位。触摸取消、失焦与牌面变更会清理拖拽状态。
- 暗牌改用已有蓝色格纹牌背。牌列宽度按安全区域计算，宽屏最大 130dp 并居中；牌堆为所有牌背预留宽度。
- 点击移动与拖拽移动都记录历史；撤销恢复牌列、翻面、发牌堆和已收牌组，同时以当前累计步数加一计算新分数。原网页的撤销步数公式也存在回退，本次保留「撤销仍计一步」的规则含义，修正安卓实现。
- 拒绝抬起混花 / 非降序牌组、空牌组落牌、向暗牌落牌，以及在已获胜牌面上发牌或移动。
